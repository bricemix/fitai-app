## Notes de mise à jour

- Les traductions sont stockées dans `translations_json` sur chaque `Plan` en base de données.
- L'API lit le header `Accept-Language` pour retourner les features dans la bonne langue.
- Le Flutter app envoie ce header automatiquement via `payment_service.dart` → `fetchPlans(locale: locale)`.
- Si une traduction manque pour une langue, le fallback est : `de → en → fr → colonne de base`.
